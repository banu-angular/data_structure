
# ⏱️ Time Complexity

## 🔹 Definition

Time Complexity measures how the execution time of an algorithm grows with input size `n`.

## 🔹 Big-O Notation

Describes **worst-case scenario**

| Complexity | Meaning       |
| ---------- | ------------- |
| O(1)       | Constant time |
| O(log n)   | Logarithmic   |
| O(n)       | Linear        |
| O(n²)      | Quadratic     |


# 🧠 Space Complexity

## 🔹 Definition

Amount of memory used by an algorithm.

## 🔹 Types

-   **Input Space**
-   **Auxiliary Space** (extra memory used)
